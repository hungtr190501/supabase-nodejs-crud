# Supabase + Node.js CRUD Application 🚀

A simple, modern, dark-mode Node.js CRUD (Create, Read, Update, Delete) application integrated with Supabase database hosting, designed to run locally on your Android device via DroidDeploy and be exposed globally using SSH tunnels (Serveo/Cloudflare).

---

## 1. Supabase Database Setup

To make the database connection work, follow these steps:

1. Create a free account and database project at [Supabase](https://supabase.com).
2. Go to the **SQL Editor** in your Supabase dashboard and run the following script to create the table:
   ```sql
   create table items (
     id bigint generated by default as identity primary key,
     name text not null,
     description text,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );
   
   -- Enable Row Level Security (RLS) or add policies if needed. 
   -- For a quick test setup, you can disable RLS or allow public read/write.
   alter table items enable row level security;
   
   create policy "Enable access to all users" 
   on items for all 
   using (true) 
   with check (true);
   ```

---

## 2. Environment Variables Configuration

Inside DroidDeploy, after cloning or adding this project:
1. Open the project inside DroidDeploy.
2. In the project workspace, create a file named `.env` in the root folder (using the built-in file editor).
3. Fill in your Supabase details (which you can find under **Project Settings > API** in your Supabase dashboard):
   ```env
   PORT=3000
   SUPABASE_URL=https://your-project-id.supabase.co
   SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```

---

## 3. Deploying in DroidDeploy

1. Push this folder to a GitHub repository (e.g., `https://github.com/your-username/supabase-nodejs-crud`).
2. Add a new project in DroidDeploy with the URL to your repository.
3. Configure the local port as `3000`.
4. Click **Deploy**.
5. Once running, toggle the **Public Domain Tunnel** to make it accessible to the public internet!
