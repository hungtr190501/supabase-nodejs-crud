Why did my file upload fail?

Supabase Storage requires an active public bucket named uploads and corresponding security access rules.

How to fix it in 1 minute:

  1. Go to your Supabase Dashboard's SQL Editor.
  2. Paste and run the following script to create the bucket and enable access rules: 
    -- Create uploads bucket
insert into storage.buckets (id, name, public)
values ('uploads', 'uploads', true)
on conflict (id) do nothing;

-- Enable upload policy
create policy "Public insert objects"
on storage.objects for insert
with check (bucket_id = 'uploads');

-- Enable read policy
create policy "Public read objects"
on storage.objects for select
using (bucket_id = 'uploads');
Action completed successfully.
